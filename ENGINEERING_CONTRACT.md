# Implementation contract

Python package `src/serverhub`, frontend `frontend`. Python 3.12. Production PostgreSQL; SQLite allowed only with SERVERHUB_DEV_MODE=true for isolated tests. No server access in this build.

## Backend core (backend owner)
Own settings.py, database.py, models.py, auth.py, policy.py, audit.py, jobs.py, api.py, main.py, cli.py, migrations/, tests/test_core*.py, pyproject.toml.
Settings loaded as `get_settings()` with SERVERHUB_ env prefix, database_url, dev_mode, state_dir, secret_key, public_url, allowed_origins; use same singleton throughout. SQLAlchemy synchronous sessions, `SessionLocal`, `get_db`, `utcnow()` naive UTC. Models `Base`, User, Host, Policy, Job, JobEvent, Audit, Finding, Incident, Memory, Backup, AgentCommand, SystemState. UUID string ids; `to_dict(model)` serializer. JSON payloads.
Auth: `Principal(id, role, username)`; `current_principal` FastAPI dependency; `require_owner(principal)`; `hash_secret/verify_secret`; `create_session`. For all scopes permission checks by persisted authenticated actor, not prompt. Policy `authorize(db, principal, operation, host_id=None, project=None, arguments=None, production=False)` raises `PermissionDenied`; read scopes per host; owner only control-plane policy changes; worker must call authorize at execution as well as submission.
Jobs: `register_handler(kind, handler)`; handler synchronous `(ctx, spec) -> dict`; ctx.db, ctx.job, ctx.principal, ctx.check_cancelled(), ctx.log(message, data=None), ctx.require(operation, arguments=None, production=False), ctx.heartbeat(). `Worker.run_once()` claims transactionally and executes with renewable lease; `submit_job(db, principal, kind, spec, host_id=None, ...)`. Persist log, state, results, retry, budgets and durable checkpoints. Handlers registered by `load_plugins()` in worker and main.
API common `/api`: `/auth/login` {username,password}, `/auth/me`, `/auth/logout`; `/overview`; `/hosts`, `/hosts/{id}`, `/hosts/{id}/inventory`, `/topology`; `/jobs` GET/POST, `/jobs/{id}`, `/jobs/{id}/events`, `/jobs/{id}/{pause,resume,cancel}`; `/policies`, `/users`, `/audit`, `/findings`, `/incidents`, `/memory`, `/backups`, `/settings/models`, `/emergency-stop`. Return JSON arrays for list routes; errors `{detail}`. Bearer opaque token accepted, HttpOnly session cookie supported. Login returns {token,user:{id,username,role}} (token for API), normal browser uses cookie. GET SSE `/api/events` with auth cookie. Main can include extension routers via local imports.
Models flexible: Host.inventory JSON, Job.spec JSON and result JSON, Finding.evidence JSON; AgentCommand host_id/job_id, operation, arguments JSON, state queued/leased/succeeded/failed, result JSON, expires_at, idempotency_key. Agent endpoints root-owned `node_api.py`.
Main `create_app()` and `app`, CLI `serverhub` with `serve`, `worker`, `migrate`, `create-user`, `health`.

## Node/privileged broker (node owner)
Own node/ package (agent.py/discovery.py/broker.py/security.py/watchdog.py), tests/test_node*.py. Do NOT create server models/API. Discovery `discover() -> dict`, includes observed_at, os, hardware, packages, interfaces, addresses, routes, dns, ports, services, docker, firewall, errors (partial collection explicit). Use bounded commands no shell, no env/config secrets. `analyze(inventory) -> list[dict]` evidence/severity/confidence/service/remediation; avoid asserting internet exposure from bind address.
Agent HTTPS polling protocol: POST /api/nodes/enroll {token,name,identity} -> {host_id,token}; GET /api/nodes/commands bearer per-node token -> array commands {id,operation,arguments,idempotency_key}; POST /api/nodes/report {inventory}; POST /api/nodes/commands/{id}/result {state:'succeeded'|'failed',result}. POST heartbeat optional report handles last_seen. Agent durable local command journal SQLite for duplicate side effects, refuses expired command and arbitrary exec. Config YAML root-owned, individual token state. Broker only narrowly implemented allowlist, never worker root/docker socket. Agent is unprivileged; optional separately configured root broker with peercred and root-owned allowlists. Discovery should work unprivileged real Linux. Independent rollback/watchdog explicit tool with journal protected from worker.

## AI/integrations (AI owner)
Own ai/ package and integrations/ package and catalog/ plus tests/test_ai*.py and tests/test_integrations*.py. No models/core edits.
Providers OpenAI-compatible and Ollama with bounded retries, tool schema validation, budget accounting. `ai.orchestrator.register()` calls jobs.register_handler('autonomous', function). Handler ctx contract above. Import models/db lazily as needed. Route model config via settings.model_config_path or /etc/serverhub/models.yaml; secrets via env references only. `integrations.registry` types and static operation allowlist; config local YAML with env refs, URLs fixed by owner and TLS validated, no AI arbitrary URLs. `integrations.execute(operation: str, arguments: dict, *, config=None) -> dict` and `operation_schemas()`. Public API integration routes root-owned. Tool orchestration must call ctx.require and controlled node dispatch `from serverhub.node_api import dispatch_command`; dispatch(db, host_id, operation, arguments, job_id) yields durable command handle; no direct root/docker socket. Provide read and write on HA/AdGuard via official APIs with checkpoints/validation rollback. Docker actions delegated broker with deployment manifests reviewed constraints. External API contracts tests via httpx.MockTransport and docs explicitly not live verified.

## Frontend (frontend owner)
Own frontend/ only. React/TS Vite. All pages use real fetch /api endpoints contract, no demo fallback. Dark polished responsive dashboard, login, host topology/details, Docker, network/ports, security, chat submits autonomous job {kind:'autonomous',host_id,spec:{prompt}}, jobs live events, policy/user administration, monitoring derived inventory and backend histories, incidents/backups/memory/audit, model config. Null/empty/error honest. Typed API. Auth cookies, bearer token optional kept only in memory, no localStorage secrets. Accessible keyboard. SSE for refresh fallback polling. Build + tests (Vitest/Testing Library if practical). Node 22+.

## Native ops (ops owner)
Own packaging/, scripts/, docs/installation.md, docs/upgrade.md, docs/recovery.md, docs/operations.md, docs/security-boundaries.md, tests/test_packaging*.py. No core code except ops/ package if needed. Native installer Ubuntu24/Debian arm64 checks, dedicated api/worker/node/broker accounts, PostgreSQL roles/password handling, root-owned code/env configs, systemd hardening and permission split; installer --check and --root DIR --plan/--stage for isolated non-privileged validation (must not mutate real host in staging). Pin dependencies from generated requirements.lock (root makes lock), install wheel and frontend built release. Migration CLI with SERVERHUB_DATABASE_URL. Backup/upgrade/rollback/uninstall dryrun and protected backups, independent systemd watchdog. backup manager code `ops/backup.py` / `ops/release.py` allowed; root will wire job handlers/API. Do not let worker modify protected policy, audit, backup, broker allowlists. Document actual boundaries and unavailable verification. CI .github/workflows tests PG, build frontend, scans and release validation; root owns final report.

## Root integration/QA
Root owns node_api.py, extensions.py, mcp.py, ops API wiring, docs architecture/admin/api/integrations/release report, full system integration testing, lockfiles, artifacts/publishing. Coordinate schema changes by messages. Agents should create meaningful git commits only for their OWN files (shared repo initialized root). Never git add -A.
