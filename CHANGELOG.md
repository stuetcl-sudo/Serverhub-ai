# Release notes

## 1.0.0 source delivery — 22 October 2026

Implemented native FastAPI controller, PostgreSQL migrations, durable supervised jobs and interval schedules, operation policies, separate node identities, evidence-based inventory/graph/metrics/incidents, controlled node broker, AI provider/tool orchestration, documented integration adapters, Git candidate development workflows, real-data administration console, OAuth/PKCE MCP endpoint, protected native backup/recovery, signed update validation and installation staging.

This source delivery is not declared production-ready. The precise verification record and unimplemented capabilities are in `docs/delivery-report.md`. Native whole-VM installation, systemd identities/hardening, ARM64, live external APIs/models, broad autonomous remediation and generic application production deployment require further verification or implementation.
