# Release notes

## Stability and autonomy overhaul — 2026-10-22 (review candidate)

- Native install journal, stable generated credentials, phase resume, safe migration
  directory/import paths, normalized readable assets and optional sandbox masks.
- Pinned native Ubuntu build workflow and backed-up local-root upgrades with an
  independent rollback timer; no automatic destructive schema downgrade.
- Owner-only model setup API/UI: discovery, capability and real harmless tool test,
  private literal HTTP consent, bounded provider errors and DB-isolated routes.
- Identity/host/argument/environment/expiry-scoped autonomy profiles and exact
  structured denial evidence. Worker model configuration remains read-only.
- Worker liveness, owner diagnostics, first-run wizard, readable tool history,
  deterministic verification and explicit partial job outcomes.
- Disposable Ubuntu/systemd installation, interrupted resume, delegated AI job,
  denied protected operation and upgrade/rollback regression coverage in CI.


## 1.0.0 source delivery — 22 October 2026

Implemented native FastAPI controller, PostgreSQL migrations, durable supervised jobs and interval schedules, operation policies, separate node identities, evidence-based inventory/graph/metrics/incidents, controlled node broker, AI provider/tool orchestration, documented integration adapters, Git candidate development workflows, real-data administration console, OAuth/PKCE MCP endpoint, protected native backup/recovery, signed update validation and installation staging.

This source delivery is not declared production-ready. The precise verification record and unimplemented capabilities are in `docs/delivery-report.md`. Native whole-VM installation, systemd identities/hardening, ARM64, live external APIs/models, broad autonomous remediation and generic application production deployment require further verification or implementation.
